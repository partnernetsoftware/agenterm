# ui-snapshot selection boundary evidence

This directory records the completed experiment specified by
`plan/archive/design-ui-snapshot-selection-boundary-experiment.md`. It decides only
whether an opt-in text-reparse adapter is admissible for a later product leaf.
It does not add a public option or change an ordinary `ui-snapshot` reply.

The frozen inputs remain under their original evidence owner,
`research/qjswasm-host-reply-wire-cost/replies/workbench-smoke/`.
`snapshot-manifest.json` binds their envelope and extracted-document hashes.
`measurements.json` preserves every reported sample, `receipt.json` gives the
machine-readable verdict, and `RESULTS.md` contains the decision trace and
rerun commands.
