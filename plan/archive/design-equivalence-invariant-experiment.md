| 字段 | 值 |

## 0. 背景与已定、不在本实验讨论范围内的事

**北极星**：自我进化——未来由 LLM/agent 产出原生能力。但「给二进制就执行」是一个
**无法验证的执行面**：agent 产出的东西没人验（Thompson trusting-trust 在 agent 自产代码下的放大）。
公开解法是 **diverse double-compilation**：同一份源经两条独立路径产出，结果须一致。
Q1 已无意搭好雏形——**一份 IR、两个独立降级器**。

**已定、本实验不再讨论（编号）**：

0.1 层数之争已判：2 层（Q0）。
0.2 中立 IR 可**有边界**地推迟 ABI/布局（Q1 判决：bounded neutrality）。**ABI 摆放机制可推迟**；
    泄漏的是 **OS 接口内容**（L1 reach、L2 arity、**L3 结构体布局**、L4 出参宽、L5 哨兵）。
0.3 `pure_compute` 两 ABI **逐字节相同**且两侧都有执行证据；`spawn` 两降级**零共享**。
0.4 宿主是 Windows 无 WSL：Win64 可真跑，SysV 只能交叉字节测量。**这是既定环境约束，不是本实验变量。**

**病灶探测器（§1 硬约束的总纲）**：任何为了让「等价可验证」这个结论好看，而
**把两个降级器往一起拉平**（例：让 SysV 也预留 Win64 影子空间、把 spawn 归一成同一套结构体）
的冲动，是本实验要**检测**的病，不是要满足的需求——那等于重演 Q1 警告的「选一个 ABI 再打补丁」，
把目标假设重新烘焙进「中立」区。真出现就**记为发现**，绝不偷偷做。

## 1. 硬约束（违反则实验无效）

### 1.1 「结构性」的定义（本实验的核心判准）

一条不变量算**结构性**，当且仅当：**违反了就拿不到可运行的制品**——等价检查在
「产出可执行字节」这条**关键路径**上，不是一个可以忘记跑的旁路脚本。
可操作化：存在一个制品类型，其**唯一**构造入口会执行等价检查；检查不过则**不产出制品**，
下游（JIT/落盘）拿不到字节。对照物（要击败的对象）是「build 完另跑一个 `check_equiv.ps1`」——
那是**事后检查**，可被忘记。

### 1.2 不得靠拉平降级器来制造等价

见病灶探测器。两个降级器保持 Q1 原样（各自的 ABI 摆放、各自的 reach、spawn 各自的 OS 实现）。
本实验**只加观测与守卫**，**不改降级产物的字节**。若为提高「可验证覆盖率」而修改任一降级器使其
产物趋同，实验无效。

### 1.3 不得滑向形式化验证 / 定理证明

**最该警惕的失败模式。** 本实验要的是**工程上可行的最小不变量**（字节比对 + 构造门），
不是「证明 fork/execve 与 CreateProcessA 语义相等」。任何时候发现自己在设计逻辑系统 /
写等价性证明 / 引入 SMT，**立即停，重读本节**。对「零共享」的降级（L3），正确的动作是
**判定其为不可验证区并如实标注**，而不是去证明它们相等。这份**克制本身就是结论的一部分**。

### 1.4 度量不得事后调整

判据（§3）动手前钉死。任何度量口径的改动必须在 §8 单列并说明动机。

## 2. 最小实验内容

| 维度 | 选择 | 理由 |
|------|------|------|
| **IR / 降级器 / 载荷** | **原样复用 Q1** 的 `ir/`（三载荷、两降级器、共享编码器） | 隔离变量：本实验只动「等价怎么判 + 怎么结构化」，降级本身不变，结果才与 Q1 连续可比 |
| **等价的候选判定层** | 字节级 / 结构congruence级 / 可观察行为级 / 不可验证 | Q1 已证明单一「字节级」不够（spawn 零共享）；**分层是本实验要产出的东西之一** |
| **结构化机制** | 构造门（私有字段 + 唯一冒烟构造入口，内部跑检查） | §1.1 的最小可行实现；用**变异体**证明它真会拦 |
| **ISA** | 只 x86_64 | 沿用 Q1；**不做第二个 ISA**（那是 Q5） |

### 等价的分层（候选定义，实测后在 §8 定稿）

- **Tier A — 字节级恒等**：两降级产物在某区段**逐字节相同**。静态可判，**无需执行**，
  是唯一能做成 §1.1 结构性守卫的层。适用：无 ABI/OS 分歧的直线中立代码。
- **Tier A′ — 结构congruence**：控制转移指令按**目标 label** 比对（而非 rel32 原始字节），
  以消除「下游因区段长度差产生的跳转偏移漂移」。仍是纯结构（同 opcode + 同目标块），无语义。
- **Tier B — 可观察行为等价**：退出码 + stdout + 可观察副作用一致。**必须执行两侧**；
  单 OS 宿主上退化为「只跑一侧 + 另一侧靠共享编码器背书」。本质是**事后差分测试**。
- **Tier C — 不可验证（仅可断言）**：两降级**零共享结构**（L3）或**目标无法在本宿主执行**。
  无机制可验，只能断言并记为覆盖上限。

## 3. 判据（**动手前认，事后不得改**）

| # | 判据 | 度量方法 | 性质 |
|---|------|----------|------|
| **①** | **结构性可达性（布尔门）**：能否把等价检查放上「产出可执行字节」的关键路径？合格条件：(a) 构造门对**变异体**返回错误且**不产出制品**；(b) 被结构性守卫覆盖的区段**非空**且等于全部非 OS 逻辑（守卫不能是空转） | 造构造门 + 造一个中立区变异体，验证 build 失败、无字节输出 | **决定性（布尔门）** |
| **②** | **覆盖率（边界的形状，主产出之一）**：每载荷每目标，结构性守卫（Tier A/A′）验证的字节 ÷ 总字节；以及被推入 Tier B/C 的字节占比 | 逐区段长度统计 | 量化（清单/边界） |
| **③** | **代价**：引入不变量的**新增 LOC 与字节**；以及它**拖慢了什么**（是否需要执行？复杂度？） | LOC 计数；说明检查是 O(bytes) 静态 memcmp、**不需执行** | 量化 |
| **④** | **不可验证区（主产出之一）**：L1–L5 各落到哪个最高可达 Tier；其中哪些**连 Tier B 都够不到**（本宿主无法执行两侧 / 零共享无结构锚点）。逐条映射表 | 带原因标注的 quarantine 区段 + 本宿主执行现实 | **决定性（清单）** |
| **⑤** | **分层定义定稿**：Tier A/A′/B/C 各自的适用条件与验证成本 | §2 分层经实测校准后定稿 | 交付（定义） |

### 度量纪律

- ② 的分子是**结构性**验证（无需执行）的字节；Tier B/C 不计入结构性覆盖（它们可被忘记跑或跑不了）。
- 报**两个覆盖数**：严格字节恒等（Tier A）与结构congruence（Tier A′）。二者之差本身是发现
  （跳转偏移漂移对字节恒等的脆弱化）。
- ③ 的 LOC 不含测试/文档；沿用 Q1 工具链（裸 `rustc`，无 Cargo）。
- 每个数字第三方可复跑，命令写进 `equiv/RESULTS.md`。

## 4. 判决树 + kill criterion + 时间盒

**事前写死。** 判据性质排序：**① 布尔门 > ④ 清单 ≈ ② 边界 > ③ 量化 > ⑤ 定义**。

```
1. 主判据 = ①（结构性布尔门）。
   若不存在任何机制能把等价检查放上关键路径（只能永远是旁路脚本），
   或构造门对变异体不拦 / 覆盖区段为空 →
     判决：「结构性不变量做不到，只能事后检查」。立即停，如实报（这会直接影响自我进化主线设计）。
2. ① 过 → ②+④ 是主产出：
   2a. 若所有载荷 ② 覆盖率 ≈100% 且无 Tier C → 判决「结构性不变量可达（全覆盖）」。
   2b. 若覆盖率对计算型载荷高、对 spawn（L3）塌陷，或存在 Tier C 区 →
        判决「结构性不变量**有边界可达**」，并交出边界（哪些泄漏落 Tier C）。
       —— 这是基于 Q1（spawn 零共享）的预判，但**接受被推翻**（2a 或回到 1）。
3. ③ 仅描述代价，不改判决方向（除非代价荒谬到否定 §1.1 的可行性）。
```

**kill criterion**：若发现要让等价「可验证」就**必须**修改降级器使其趋同（违反 §1.2），
或必须引入语义等价证明（违反 §1.3）——则命题「可做成结构性不变量」在**不作弊前提下证伪**，
停，判「只能事后检查 / 有天然上限」。

**时间盒**：做到三载荷都出 ①②③④ 为止。**不做第二个 ISA、不做优化、不做形式化验证器、
不做等价的语法糖。** 出数即停。

### §4 对账（判决树 vs §3 优先级）

- ①（布尔门）= 树的根节点。✅
- ②（边界）+ ④（清单）= 节点 2。✅ 二者同为主产出，并列。
- ③（量化）= 节点 3，明确**不改方向**。✅
- ⑤（定义）不是判决节点，是交付物：分层定义随 ②④ 的实测校准后在 §8 定稿。**显式说明其非节点。** ✅
- 穷举出口：① 不过→节点 1 出口；① 过且全覆盖→2a；① 过且塌陷/有 C→2b。三类组合均有出口。✅

## 8. 实验结论回填（2026-08-08，实测）

实现落在 `research/dynamic-core/equiv/`（复用 Q1 `ir/`，独立 `rustc` 编译）；完整数字、
覆盖率表、Tier×Leak 映射、复跑命令见该目录 `RESULTS.md`。以下是回填要点。

### 判决：**有边界可达（bounded structural achievability）**

判决树逐步走：

1. **① 布尔门通过。** 构造门 `VerifiedArtifact`（私有字节字段 + 唯一构造入口 build，
   内部跑 `check_congruence`）：变异体（篡改一个中立区字节）令 build 返回 `Err`、
   **不产出制品、拿不到字节**（负测试实测 `NeutralBytesDiffer`）。守卫覆盖区非空——
   三载荷的中立字节两目标**逐字节相同**（246/246、676/676、623/623）。**守卫非空转。**
   → 进节点 2。
2. **② + ④ 主产出。** 覆盖率对计算型载荷 100%（`pure_compute` 整像 byte-identical），
   对 `spawn` 塌陷（intent 泄漏占 win64 **55.6%**、sysv **44.8%**），且存在 Tier C 区 →
   命中判决树 **2b：结构性不变量有边界可达**。边界 = **intent 区（即 Q1 的 L1–L5，OS 接口内容）**。
3. **③ 仅描述代价**（~55 LOC 守卫 + ~60 LOC 区段记录；**零运行时、零执行、产物 0 字节**），
   不改判决方向。

**未触发 kill criterion**：无需修改降级器使其趋同（§1.2 未违反），无需引入语义等价证明
（§1.3 未违反——对零共享的 L3/spawn 直接判 Tier C，不去证明 fork/execve ≡ CreateProcessA）。

### 数字表（判据 × 载荷，见 RESULTS ②③）

- **① 结构性守卫**：过；变异体被拒；三载荷经门执行全部 OK（163 / `a49d2cbecc13994f` / exit=07）。
- **② intent 泄漏占比（= 不可结构验证的比例）**：pure 0% / rhp sysv 29.3% win 40.8% /
  spawn sysv 44.8% win 55.6%。中立字节两目标恒等。
- **③ 代价**：守卫 ~55 LOC + 区段记录 ~60 LOC；Coverage 测量另 ~40 LOC；运行时 O(bytes) memcmp，
  **不需执行**，产物不增字节。

### 分层定义定稿（⑤，见 RESULTS ⑤）

Tier A 字节恒等 / A′ 结构congruence（按 label）/ A− 机制（同 opcode，ABI 常量）/
B 可观察行为（需两侧执行，本质事后差分）/ C 不可验证（零共享 L3、宿主不可执行、或 L5 连等价都无法陈述）。
**结构性不变量只活在 A/A′/A−（不可遗忘、无需执行）；B 天然事后；C 是记录在案的上限。**

### 与规格不符之处（如实列）

1. **SysV 只测字节不执行**（无 WSL）——封面允许。其中立核靠与**已执行**的 Win64 中立核逐字节相同
   而获得「证据转移」；其 intent 区在本宿主是 Tier C。
2. **`equiv_lower.rs` 是 Q1 `common.rs` 的副本**而非 `#[path]` 复用——Q1 的 `lower_inst`/`lower_op`
   私有，无法从外部驱动以观测区段边界。emit 逻辑逐字保留（中立字节与 Q1 一致，`pure_compute` 仍 281）。
3. **Coverage 测量（~40 LOC）与守卫（~55 LOC）分开计**，避免夸大不变量自身代价。

### 推翻/超出预期的地方（最值钱）

- **预判之外的发现（Q1 未surface）**：**即使中立核也非整体字节恒等**——帧大小（M1）与入口 ctx 寄存器（M2）
  是烘焙进共享路径字节的 ABI 事实，字节发散但行为平凡。**字节恒等严格强于等价，连中立核内都如此**——
  这正是不变量必须用「区段模型 + 按 label 比对跳转」而非整像 `memcmp` 的原因（整像 memcmp 只对 pure 通过，
  会拒绝所有真实载荷）。
- **两重上限叠加**：spawn 的 SysV `SpawnWait`（fork/execve/wait4）既无结构锚点（零共享）又无法在本宿主执行——
  **纯 Tier C**。这就是「可验证性」的天然覆盖上限，如实报：**agent 产出的计算逻辑可获不可遗忘的结构性验证，
  但 OS 接口胶水是任何结构性不变量都关不上的信任洞。**

### 诚实条款

**未为让结论好看而改任何度量。** 明确拒绝了「拉平降级器提升覆盖率」（§1.2 病灶）与「证明零共享降级相等」
（§1.3 滑向定理证明）两条作弊路径——两者都会让覆盖率数字更漂亮，但会伪造结论。结论保持 bounded，边界如实给出。
