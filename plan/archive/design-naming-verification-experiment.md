# Q14 — Behavioural verification of naming bindings (design / criteria)（历史规格）

> **不进 must-ship，不改 PRD 能力状态。** 研究轨投影，实现在
> `research/dynamic-core/naming/`，不挂进根 workspace。净室：不读、不引用任何既有实现源码。

**Host:** Windows Server 2022 / x86_64 真机（`D:\dev\agenterm`）, `rustc 1.97.0 -O`.

## §0 背景 + 已确定、不在本实验范围内的事

Q4 判定「符号 index 1 **是不是真的** `CreateFileA`」**不可查**，理由是循环
（要验它就得调它）。Q13 沿用该判定，把结论限定为「布局可检测 **modulo 命名**」，于是
信任集从 {命名 + 布局} 收窄到 **{命名}**，命名被 Q4/Q13 共同宣布为不可约（R3）。

**本实验挑战这个判定。** 证据在 Q13 自己的 FACT1：它建一个自己命名的文件、调它认为是
`FindFirstFileA` 的符号、要求返回串等于自己给的名字——**若那个符号根本不是
`FindFirstFileA`，这个检查同样会 FIRE。** 即 Q13 已无意中做了行为式命名验证。

**已确定、不重测：** ① Q13 的布局检测结论；② Q4 的结构守卫覆盖边界；③ 四原语模型
（sym+call）本身；④ intent 边界之外零观测（Q15）。本实验只问命名绑定这一条。

## §1 硬约束（违反则实验无效）

1. 只用四原语（③ sym + ④ call），净室重写，与 Q13 逐字节同角色。
2. 检测全在载荷侧；**内核字节增量必须为 0**（否则滑向符号完整性基础设施）。
3. **病灶探测器**：任何滑向做「符号服务器 / PDB 解析 / 签名验证 / 完整 Win32 覆盖」的
   冲动，是本实验要**检测**的病，不是要满足的需求。要的是**能验到什么程度、根信任集多大**
   的判定，不是一套验证系统。真需要就记为发现。
4. 负探针姿态（沿用 Q13）：不断言「能验」，而是**把绑定故意指错**（把 slot 解析成另一个
   export）然后**要求它报警**。

## §2 最小实验内容

| 维度 | 选择 | 为什么 |
|---|---|---|
| 符号样本 | 3 个纯函数（`lstrlenA`/`MulDiv`/`lstrcmpiA`）+ 1 个 OS 往返簇（`CreateFileA`/`WriteFile`/`ReadFile`/`CloseHandle`）+ 无契约类若干（resolver / `Sleep` / `ExitProcess`） | 覆盖「有契约 vs 无契约」这条假设分界的两侧 |
| ISA / OS | x86_64 / Windows 单点 | 隔离变量；命名轴与 ISA 轴正交（Q5 已测） |
| 不做 | PDB、符号服务器、PE export 解析、签名、完整覆盖 | §1.3 病灶 |

## §3 判据（写代码前钉死，事后不改）

- **① 布尔门（主判据之一）**：对 ≥1 符号，正确绑定的行为契约 self-check 必须 PASS，
  故意绑错必须 FIRE。度量：过/不过。
- **② 覆盖分类（清单产出）**：哪类符号可验 / 不可验。假设分界 = 有无可构造的
  「已知入→已知出」契约或 OS 往返。**自己判定**，如实报边界。
- **③ 代价**：每符号检测 LOC + 内核字节，对照 Q13 ~18–38 LOC/fact、+0 内核字节。
- **④ 循环性 / 根信任集（主判据之一，最要紧）**：构造「X 的检测调用了哪些别的符号」的
  依赖图，问它是否收敛到一个根集。**测 N。** 「不可约」和「可收敛到小根集」是两个完全
  不同的结论。
- **⑤ 信任图改法**：给出 SYNTHESIS R3 + ⑤ 的具体改法。

度量口径：SKILL §2.5 四元标签 + 执行状态（真机执行 / 仅字节测量）。

## §4 判决树 + kill criterion + 时间盒

```
主判据 = ① ∧ ④。
1. 若 ① 对所有测试符号 FIRE 都不触发（负探针无法区分对/错绑定）
   → kill：命名确实不可行为式验证，Q4/Q13 成立。立即停，如实报。
2. ① 触发（可区分）但 ④ 不收敛（每符号引入新的不可约信任，N→符号表大小）
   → 命名可验但无收益（仍需信任 O(符号数)）。
3. ① 触发且 ④ 收敛到小 N
   → 判决：命名可行为式验证，可收敛到 N 个根 / 一个残留类。对 Q4/Q13 的实质修正。
kill criterion: ① 全不触发 → 命题证伪。
时间盒: 出 ①②④ 即停。不做 PDB / 符号服务器 / PE 解析 / 完整 Win32 覆盖。
```

## §7 本实验不回答

- 单个符号在**所有**输入上是否是真符号（只验构造输入上的行为契约 = Tier B）。
- Thompson trigger（测试期诚实、运行期恶意）——**结构上不可验**，记为残留。
- 无契约符号的绑定真值——记为残留。
- 内核 / OS 本身是否被 trojan（进程外，= Q15 边界外信任）。
